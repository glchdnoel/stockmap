# 맥 동기화 (토스증권 → 스톡맵)

맥북에서만 실행되는 작은 프로그램이에요. 토스증권에서 **보유 종목만 조회**해서 스톡맵의 '가져오기' 파일로 저장해요.

## 안전 장치
- **조회 전용:** 토큰 발급, 계좌 목록, 보유 종목 3가지 호출만 허용해요. 주문 기능 코드는 아예 없고, 다른 호출은 코드에서 막아요.
- **키 보관:** client_secret은 **macOS 키체인**에만 저장해요. 파일이나 명령어 기록에 남지 않아요.
- **외부 패키지 없음:** 맥에 기본으로 있는 파이썬 기능만 써요.
- **계좌번호 비노출:** 계좌번호는 화면에도, 결과 파일에도 쓰지 않아요.
- **파일 권한:** 결과 파일은 나만 읽을 수 있는 권한(600)으로 저장해요.

## 처음 한 번
1. 토스증권 웹(WTS) → 설정 → Open API에서 `client_id`, `client_secret`을 발급받아요.
2. 같은 화면의 **허용 IP 관리**에 지금 집 인터넷 IP를 등록해요. 다른 와이파이(학교, 카페)에서는 IP가 달라서 막혀요.
3. 터미널에서 이 폴더로 이동해 실행해요.
   ```
   python3 stockmap_sync.py setup
   ```
   처음이면 맥이 '개발자 도구 설치'를 물어볼 수 있어요. 설치하면 돼요.

## 쓸 때마다
- `토스증권 동기화.command`를 더블클릭하거나, 터미널에서 `python3 stockmap_sync.py`를 실행해요.
  - 처음 더블클릭할 때 맥이 막으면 우클릭 → 열기를 누르세요.
- 다운로드 폴더에 `stockmap-holdings.json`이 생겨요.
- 스톡맵 → 종목 관리 → **가져오기(JSON)**로 불러와요. 가져온 뒤 파일은 지워도 돼요.

## 그룹(테마) 지정 (선택)
`groups.example.json`을 `groups.json`으로 복사한 뒤 원하는 대로 고쳐요. 지정하지 않은 종목은 '미국'/'한국'으로 묶여요.

## 키 지우기
```
python3 stockmap_sync.py forget
```
더 확실히 하려면 토스증권 WTS에서 키를 폐기하세요.

## 알아 둘 점
- 토스증권 문서에는 '조회 전용 키' 옵션이 없어요. 그래서 키 자체는 주문 권한을 가질 수 있어요. 키를 절대 남에게 주거나 웹앱에 넣지 마세요.
- 토큰은 하나만 유효해요. 다른 토스 API 프로그램을 같이 쓰면 서로의 토큰을 무효로 만들 수 있어요.
- 자동 점검: `python3 test_sync.py` (모의 서버 사용, 실제 접속 없음)
