# 맥 동기화 (토스증권 → 스톡맵)

맥북에서만 실행되는 작은 프로그램이에요. 토스증권에서 **보유 종목만 조회**해서 스톡맵의 '가져오기' 파일로 저장해요.

## 안전 장치
- **조회 전용:** 토큰 발급, 계좌 목록, 보유 종목 3가지 호출만 허용해요. 주문 기능 코드는 아예 없고, 다른 호출은 코드에서 막아요.
- **키 보관:** client_secret은 **macOS 키체인**에만 저장해요. 파일이나 명령어 기록에 남지 않아요.
- **외부 패키지 없음:** 맥에 기본으로 있는 파이썬 기능만 써요.
- **계좌번호 비노출:** 계좌번호는 화면에도, 결과 파일에도 쓰지 않아요.
- **파일 권한:** 결과 파일은 나만 읽을 수 있는 권한(600)으로 저장해요.

## 처음 한 번
1. 토스증권 웹(WTS) → 설정 → Open API에서 `client_id`, `client_secret`을 발급받아요.
2. 같은 화면의 **허용 IP 관리**에 지금 집 인터넷 IP를 등록해요. 다른 와이파이(학교, 카페)에서는 IP가 달라서 막혀요.
3. 터미널에서 이 폴더로 이동해 실행해요.
   ```
   python3 stockmap_sync.py setup
   ```
   처음이면 맥이 '개발자 도구 설치'를 물어볼 수 있어요. 설치하면 돼요.

## 쓸 때마다
- `토스증권 동기화.command`를 더블클릭하거나, 터미널에서 `python3 stockmap_sync.py`를 실행해요.
  - 처음 더블클릭할 때 맥이 막으면 우클릭 → 열기를 누르세요.
- 다운로드 폴더에 `stockmap-holdings.json`이 생겨요.
- 스톡맵 → 종목 관리 → **가져오기(JSON)**로 불러와요. 기억하기를 끈 경우 다음에도 이 파일이 필요하니 보관하세요.

## 그룹(테마) 지정 (선택)
`groups.example.json`을 `groups.json`으로 복사한 뒤 원하는 대로 고쳐요. 지정하지 않은 종목은 '미국'/'한국'으로 묶여요.

## 키체인 허락 창은 한 번만 (2026-11-14)
`client_id`와 `client_secret`을 키체인 **한 항목**에 같이 저장해요. 그래서 동기화나 중계를 켤 때 허락 창이 **한 번만** 떠요.
예전 방식(두 항목)으로 저장돼 있으면, 다음 실행 때 한 번만 두 번 묻고 자동으로 한 항목으로 합친 뒤 예전 항목을 지워요(이때 삭제 허락을 물을 수도 있어요). 다시 setup할 필요 없어요.

## 예전에 setup을 한 적이 있다면 (키체인 보호 강화)
2026-11-11부터 키를 저장할 때 허용 앱 목록을 비워 둬요(`-T ""`). 그래서 어떤 프로그램이든 키를 읽으려면 맥이 매번 허락을 물어요.
이미 저장된 항목에는 예전 권한이 그대로 남아 있으니, 아래 순서로 지우고 다시 만드세요.
1. `python3 stockmap_sync.py forget` (기존 항목 삭제)
2. `python3 stockmap_sync.py setup` (새 권한으로 다시 저장)
3. 동기화할 때 맥이 키체인 사용 허락을 물으면 **허용**을 누르세요. **항상 허용**을 누르면 다시 묻지 않게 돼서 이 보호가 사라져요.

## 국내 종목 실시간 시세 (맥 중계)
스톡맵은 국내 종목 실시간 시세를 Finnhub에서 못 받아요. 맥에서 중계 프로그램을 켜 두면 토스 시세를 2초마다 받아서 이 맥에서 연 스톡맵에 건네줘요.
**`스톡맵 중계 켜기.command`를 더블클릭**하면 중계가 켜지고 크롬으로 스톡맵이 열려요. 터미널로 하려면:
```
python3 stockmap_relay.py --open
```
그 창이 열려 있는 동안만 중계가 돌아요(최소화는 괜찮아요). 다 봤으면 창을 닫으세요.

1. 처음 실행하면 **중계 토큰**(40자리)이 나와요. 스톡맵 → 설정 → '맥 중계 토큰'에 붙여넣으세요. 다시 보려면 `python3 stockmap_relay.py token`이에요.
2. 키체인 허락 창이 뜨면 **'허용'만** 누르세요('항상 허용' 금지).
3. 스톡맵 위쪽에 **'국내 실시간'** 배지가 뜨면 성공이에요. 크롬이 "로컬 네트워크 기기에 접근" 허락을 물으면 허용하세요(이 맥 안의 중계 프로그램이에요).
4. 끝내려면 터미널에서 `Ctrl + C`예요.

- 이 맥에서만, 그리고 토스에 허용 IP로 등록한 네트워크에서만 동작해요. 핸드폰에서는 안 돼요.
- 국내 종목도 1시간(1분봉)·1주~3년(일봉) 등락이 나와요. 기간을 처음 고를 때 중계가 토스에서 일봉을 받느라 몇 초 걸려요(6시간 캐시).
- 동기화(`stockmap_sync.py`)를 같이 실행하면 토큰이 바뀌어서, 중계 프로그램이 키체인 허락을 한 번 더 물을 수 있어요.
- 자동 점검: `python3 test_relay.py` (모의 서버 사용, 실제 접속 없음)

## 키 지우기
```
python3 stockmap_sync.py forget
```
더 확실히 하려면 토스증권 WTS에서 키를 폐기하세요.

## 알아 둘 점
- 토스증권 문서에는 '조회 전용 키' 옵션이 없어요. 그래서 키 자체는 주문 권한을 가질 수 있어요. 키를 절대 남에게 주거나 웹앱에 넣지 마세요.
- 토큰은 하나만 유효해요. 다른 토스 API 프로그램을 같이 쓰면 서로의 토큰을 무효로 만들 수 있어요.
- 자동 점검: `python3 test_sync.py` (모의 서버 사용, 실제 접속 없음)
