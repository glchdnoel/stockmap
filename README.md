# 스톡맵 (StockMap)

내 포트폴리오를 **실시간 히트맵**으로 보는 개인용 웹앱이에요.
- 박스 크기는 평가금액(비중), 색은 오늘 등락률(초록은 상승, 빨강은 하락)이에요.
- 종목을 테마(그룹)별로 묶어서 보여 줘요.
- 미국 주식과 ETF는 Finnhub 웹소켓으로 체결될 때마다 갱신돼요 (화면 갱신은 최대 1초에 한 번).
- 한국 주식은 실시간을 지원하지 않아요. 현재가를 직접 입력하면 그 값으로 표시돼요.

## 사용 방법
1. [finnhub.io](https://finnhub.io)에 무료로 가입하고 대시보드에서 API 키를 복사해요.
2. 앱의 **설정**에 키를 붙여 넣고 저장해요. 키는 이 브라우저에만 저장돼요.
3. **종목 관리**에서 티커, 수량, 평단, 그룹을 추가해요.
4. 설정에서 USD→KRW 환율을 실제 값에 맞게 바꿔 주세요 (기본값 1400은 임시값이에요).

미국 장 시간(한국 시간, 서머타임 해제 기간 기준):
- 프리마켓: 18:00
- 정규장: 23:30 ~ 06:00
- 애프터마켓: ~ 10:00

## 구성
- `index.html`, `style.css`, `app.js`: 앱 본체 (빌드 과정 없음)
- `vendor/d3-hierarchy.min.js`: 트리맵 계산 라이브러리 (무결성 해시로 검증)
- `SECURITY.md`: 보안 설계와 남은 위험
- `PROMPTS.md`: 사용한 프롬프트, Aside 점검용 프롬프트
- `tests/test_app.py`: 자동 보안·동작 점검 (Playwright)

이 앱은 정보 표시용이며 투자 조언이 아니에요.
